    Home

    Cookbook Central is a social media website where users can share recipes and follow each other. A database driven website will record information about recipes, ingredients, reviews, and users. The goal of Cookbook Central is to provide users with a free, easy-to-access place to store all their favorite recipes, as well as allow users to discover new recipes. Users will be able to post their own recipes, view others' recipes, and leave reviews on any recipes with a rating and comment. They’ll also be able to save their own recipes or other users’ recipes to their cookbook, allowing the user to have access to dozens of their favorite recipes.

    Table Name Description
    Recipes An entity table that contains data about recipes.
    Recipe Ingredients An intersection table that supports the M:N relationship between Recipes and Ingredients.
    This table contains data about which ingredients are used in which recipes.
    Ingredients An entity table that contains data about ingredients.
    Saved Recipes An intersection table that supports the M:N relationship between Users and Recipes.
    This table contains data about which recipes are saved by which users.
    Reviews An entity table that contains data about reviews posted by users on recipes.
    Users An entity table that contains data about users.
    User Followers An intersection table that supports the M:N relationship between Users and Users.
    This table contains data about the follower-followed relationship between users.
